# blueprint — Claude Code Instructions

## Tech Stack

- **CLI**: Go (cobra + go-selfupdate)
- **Hooks**: Python (fallback), Go binary (primary)
- **Installer**: Bash + gum TUI
- **Skills**: Markdown (SKILL.md prompt files)
- **Workspace**: YAML frontmatter (Obsidian Dataview compatible)

## Development

### Common Commands

```bash
cd cli && make build-all             # Build all 3 binaries (arm64, amd64, linux)
cd cli && make build-mac-arm         # Build macOS Apple Silicon only
./install.sh                         # Run the installer locally
blueprint audit                      # Test audit hook
blueprint status                     # Show SDLC status
blueprint update                     # Self-update CLI + skills
```

## Workflow

```
/plan → /plan-review → /plan-approved → /plan-check → /pr → /review → /address-pr → /finish
```

**Branch flow**: `feat/feature-name → staging → main`

- Feature branches always target `staging`
- `staging → main` happens via PR after review
- Direct pushes to `main` are blocked by hooks

## Testing Rules

**Always use targeted tests** — fast feedback:

```bash
cd cli && go test ./... -run TestName     # Go CLI tests
python -m pytest tests/ -k "test_name"    # Python hook tests (if added)
```

Full suite → ask the user to run it in their own terminal.

## BLUEPRINT Workspace

```
blueprint/
├── .config.yml ← Project config (staging branch, language, stack)
├── backlog/    ← Ideas not yet planned (/backlog)
├── live/       ← Currently in development (/plan)
├── upstream/   ← Shipped and merged (/finish)
└── expired/    ← Cancelled or deferred
```

## Commits

Format: `<emoji> <type>[(scope)][!]: <description>` (present tense, lowercase)

```
✨ feat: add dark mode toggle
✨ feat(installer): add gum multi-select menu
🐛 fix(audit): correct plan-check skip detection
📚 docs: update README with install instructions
```

**Never** add AI signatures (`Co-Authored-By`, `Generated by`, etc.)

## Updates

Run `blueprint update` to get the latest skills, hooks, and CLI binary.

## Project-Specific Notes

- This IS the BLUEPRINT repo — skills in `skills/` are the source of truth
- `temp/` is gitignored — working files during development
- Pre-compiled binaries are gitignored (`cli/blueprint-darwin-*`, `cli/blueprint-linux-*`)
- Skills install to `~/.claude/skills/` on user machines, but source lives here in `skills/`
- Audit hook source: `hooks/blueprint.py` (Python fallback) + Go binary (primary)
